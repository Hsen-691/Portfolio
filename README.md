# Hussein Adib Portfolio

## Run
Open `index.html` directly, or use VS Code Live Server.

## Edit profile image
Replace `assets/images/profile-placeholder.svg` with your photo and update the image path in `index.html` if needed.

## CV
The CV download button points to `assets/cv/Hussein_Adib_CV.pdf`.

## Projects
Edit the three project cards inside the `#projects` section in `index.html`.
